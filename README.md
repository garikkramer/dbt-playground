# TPC-H dbt Playground

Этот репозиторий представляет собой аналитический плейграунд для базы данных DuckDB с использованием **dbt** (data build tool). Проект основан на стандартной схеме данных TPC-H и включает в себя адаптацию 22 стандартных аналитических SQL-запросов TPC-H в dbt-модели.

## Структура проекта

Проект организован в соответствии с лучшими практиками dbt:

1. **Конфигурация dbt:**
   - `dbt_project.yml` — основной конфигурационный файл проекта dbt.
   - `profiles.yml` — локальный файл профилей подключения к DuckDB.

2. **Слои моделирования (`models/`):**
   - **Источники (`models/staging/sources.yml`)**: описывает исходные таблицы TPC-H, хранящиеся в базе данных `tpch-sf1.db`.
   - **Staging (`models/staging/`)**: базовые модели (представления/views), которые ссылаются непосредственно на источники (`stg_customer.sql`, `stg_lineitem.sql` и т.д.).
   - **Queries (`models/queries/`)**: 22 классических запроса TPC-H (`q1.sql` - `q22.sql`), переписанные с использованием макроса `{{ ref() }}` для связи со staging-слоем. При запуске они материализуются как таблицы (`table`) для обеспечения высокой производительности чтения.

## Быстрый старт и настройка среды

### 1. Подготовка виртуального окружения
Для изоляции зависимостей используется виртуальное окружение Python:

```bash
# Создание чистого виртуального окружения
python3 -m venv .venv --clear

# Активация окружения (macOS/Linux)
source .venv/bin/activate
```

### 2. Установка зависимостей
Установите необходимые пакеты из `requirements.txt` (включая `dbt-duckdb` и `duckdb`):

```bash
pip install -r requirements.txt
```

## Работа с dbt

Поскольку настройки подключения вынесены в локальный `profiles.yml` в корне проекта, при выполнении команд dbt необходимо явно указывать директорию профиля с помощью флага `--profiles-dir .`.

### Проверка подключения
Проверьте, что dbt видит базу данных и профиль настроен корректно:
```bash
.venv/bin/dbt debug --profiles-dir .
```

### Запуск моделей (сборка данных)
Соберите все staging и query модели в вашей локальной базе данных DuckDB:
```bash
.venv/bin/dbt run --profiles-dir .
```

### Тестирование данных
Вы можете запустить тесты для проверки качества данных:
```bash
.venv/bin/dbt test --profiles-dir .
```

### Генерация документации
dbt автоматически строит интерактивную документацию по схеме данных, включая граф зависимостей (lineage DAG):
```bash
# Генерация документации
.venv/bin/dbt docs generate --profiles-dir .

# Запуск локального веб-сервера для просмотра документации (откроется в браузере)
.venv/bin/dbt docs serve --profiles-dir .
```

## База данных

Проект работает напрямую с базой данных `tpch-sf1.db` (DuckDB), которая расположена в корневом каталоге проекта. Все изменения и новые таблицы/представления dbt создает внутри этой БД в соответствующих схемах.
